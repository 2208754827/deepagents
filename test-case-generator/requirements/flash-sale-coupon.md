# 抢购活动与优惠券

## 2.5.2 添加抢购活动

添加活动页面，红色星号代表必填信息

规则：
1.参加抢购的商品必须指明某个具体规格，比如商品的不同颜色。
2.抢购活动添加成功后，不允许修改限购数量。
3.抢购活动进行中，已有用户下单购买后，不再允许编辑抢购活动信息

## 2.5.3 抢购活动的状态

抢购活动添加成功后，抢购活动有多种状态：已过期，未开始，进行中，已售罄，已结束

规则：
1.当前时间达到活动的开始时间，则活动状态由"未开始"变为"进行中"
2.活动的开始时间早于当前时间，结束时间晚于当前时间，则新建的活动状态为"进行中"
3.参加抢购活动的商品售完后，活动的状态变为"已售罄"
4.当前时间达到活动的结束时间，则活动的状态由"进行中"变为"已结束"
5.抢购活动的结束时间早于当前时间时，则新建的活动状态为"已过期"

## 2.5.4 商品抢购活动展示效果

抢购活动开始后，商城会员可以在商城前台参与抢购活动。
抢购活动结束后或者抢购商品售罄后，商品展示恢复原价。

规则：
1.抢购商品加入购物车时，要求会员必须先登录账号
2.会员抢购商品时，数量不能超过抢购活动要求的限购数量，超出时页面给出提示
3.商品加入购物车时，抢购库存数量不会减少，直到生成订单后，抢购的库存数量才会减少
4.生成订单后，取消订单，订单中的商品数量恢复到抢购的库存中
5.抢购活动结束后，商品的价格恢复原价，库存数量恢复为原价的库存数量

## 2.5.5 购物车中的抢购商品

加入购物车后，能够看到抢购活动的标记，红色的"抢"字，以及抢购活动所节省的金额

规则：编辑购物车商品数量时，不能大于抢购活动的限制数量

## 2.5.6 抢购活动的首页导航栏配置

在系统---设置---自定义导航栏，新增一个自定义导航，

## 2.5.7 抢购活动前台主页的显示

页面显示【进行中】与【即将开场】的抢购活动。
活动页面显示倒计时的内容
单个活动信息显示商品封面，商品名称，商品抢购价格，商品原价，抢购进度，抢购状态（未开场，去秒杀，已售罄）。
点击单个活动信息，可以跳转到商品详情页面（售罄的除外）。

抢购列表显示要求：
商品的抢购活动时间需要处于活动的两个小时区间内，
比如开始时间要求大于等于18点，同时结束时间要求小于等于20点

## 2.6 优惠券

### 2.6.1 优惠券后台管理列表

功能位置: 商城 -- 促销 -- 优惠券

列表字段内容

- 刷新功能 -- 单机后刷新列表内容
- 全选功能 -- 全选当前页所有优惠券
- 添加优惠券 -- 进入填写添加优惠券页面
- 发放优惠券 -- 三种图标-线下发放, 指定发放, 无需发放
- 查看优惠券 -- 查看管理当前生效优惠券
- 编辑优惠券 -- 编辑优惠券信息
- 删除优惠券 -- 点击删除优惠券
- 分页功能 -- 点击跳转分页

### 2.6.2 优惠券后台添加优惠券

- 优惠券名称 -- 优惠券名称不能超过20个字符, 必填项
- 优惠券面额 -- 优惠券可抵扣金额, 必填项
- 消费金额 -- 订单需满足的最低消费金额(必需为整数)才能使用, 消费金额不能小于或等于优惠券金额, 最大100000000, 必填项
- 发放数量 -- 发放数量限制(默认为0则无限制), 必填项
- 发放类型 -- 下单赠送(默认)/指定发放/免费领取/线下发放
  - 下单赠(无发放日期)
  - 指定发放/免费领取/线下发放(有发放日期)
- 发起起始日期 -- 发放起始日期/日期格式 YYYY-mm-dd HH:MM:SS /发放结束日期不得小于发放开始日期/必填项
- 发起结束日期 -- 发放结束日期/日期格式 YYYY-mm-dd HH:MM:SS /必填项
  - 不在发起日期范围内无法发起
- 使用起始日期 -- 使用起始日期, 日期格式 YYYY-mm-dd HH:MM:SS , 使用结束日期不得小于使用开始日期, 必填项
- 使用结束日期 -- 使用结束日期, 日期格式 YYYY-mm-dd HH:MM:SS , 必填项
  - 不在使用日期范围内容无法使用
- 可使用商品 -- 全店通用(默认), 指定商品, 指定分类, 必填项
  - 全店通用 -- 所有商品都可以使用优惠券
  - 指定商品 --指定商品可以使用优惠券 -- 选中目标商品后点击确认提交
    - 刷新商品信息, 筛选搜索, 全选商品, 查看打开商品详情页, 分页分页显示, 提交确认
    - 点击确认提交后添加到指定商品列表 -- 商品ID, 商品名称, 价格, 库存, 操作(删除)
  - 指定分类 -- 指定分类可以使用优惠券(限制商品分类使用) -- 需要选择三级分类
    - 若不选表示不限制，否则请选择到指定三级分类
- 状态 -- 有效, 无效(默认)
  - 有效 -- 可用, 可发放, 可领取
  - 无效 -- 不可用, 不可发放, 不可领取
- 提交 -- 提交保存

### 2.6.3 优惠券后台发放优惠券

优惠券发放类型说明

| 发放类型 | 发放方式                        |
| -------- | ------------------------------- |
| 下单赠送 | 优惠促销赠送, 订单促销赠送 |
| 指定发放 | 指定用户发放                    |
| 免费领取 | 用户主动领取                    |
| 线下发放 | 兑换码兑换                    |

下单赠送发放流程(无需发放)

- 创建优惠券 -- 正确填写优惠券信息
- 发放优惠券 -- 优惠促销赠送
  - 用户下单购买指定优惠促销商品后,满足条件可自动获得优惠券 -- 相同优惠券获取一次
- 发放优惠券 -- 订单促销赠送
  - 用户下单超过一定金额完成订单后,满足条件可自动获得优惠券 -- 相同优惠券获取一次

指定发放发放流程(指定发放)

- 创建优惠券 -- 正确填写优惠券信息
- 在优惠券列表中对应点击发放 -- 选中需要发放用户 -- 点击发放 -- 限发一次, 发放后用户消失

免费领取发放流程(无需发放)

- 创建优惠券 -- 正确填写优惠券信息
- 领券中心
  - 后台配置导航栏-- 首页导航进入
  - 我的商城 -- 我的优惠券 -- 领取更多优惠券 -- 进入领券中心页面
    - 进入优惠券领取页面(默认创建时间先后顺序显示)
    - 点击目标优惠券
    - 领取成功提示
    - 限领一次, 领取后消失

线下发放发放流程(线下发放)

- 创建优惠券 -- 正确填写优惠券信息
- 在优惠券列表中对应点击发放 -- 填写生成兑换码数量
- 用户获取兑换码, 兑换优惠券 -- 用户在支付时可以使用优惠券码兑换优惠券 -- 用户可以获取多个相同优惠券(每个兑换码限用一次)
