# 用户管理模块需求

## 1. 用户注册

### 1.1 注册流程

用户通过注册页面创建账号。注册时需填写以下信息：

- 用户名：4-20个字符，仅允许字母、数字、下划线
- 密码：8-32个字符，必须包含大小写字母和数字
- 确认密码：必须与密码一致
- 邮箱：符合标准邮箱格式
- 手机号：11位数字，以1开头

注册成功后，系统发送验证邮件到用户邮箱。用户需在24小时内点击验证链接完成激活。未激活账号无法登录。

### 1.2 注册限制

- 同一邮箱只能注册一个账号
- 同一手机号只能注册一个账号
- 同一IP地址24小时内最多注册5个账号

## 2. 用户登录

### 2.1 登录方式

- 用户名+密码登录
- 手机号+验证码登录
- 邮箱+密码登录

### 2.2 登录安全

- 连续5次输入错误密码，账号锁定30分钟
- 锁定期间无法登录，提示"账号已锁定，请30分钟后重试"
- 登录成功后记录登录时间、IP地址

### 2.3 登录状态

- 单个账号最多同时在3个设备登录
- 第4个设备登录时，最早登录的设备自动下线
- 用户可查看当前在线设备列表

## 3. 个人信息管理

### 3.1 信息修改

用户可修改以下个人信息：
- 昵称：1-30个字符
- 头像：支持 jpg/png，大小不超过5MB
- 个性签名：最多200个字符

### 3.2 密码修改

- 需输入原密码验证身份
- 新密码不能与最近3次使用过的密码相同
- 修改成功后所有设备需重新登录

## 4. 账号注销

- 用户可申请注销账号
- 注销前需输入密码确认
- 注销后账号数据保留30天，30天后永久删除
- 30天内可恢复账号
