# 电商购物车模块需求文档

## 1. 概述
购物车是电商系统的核心功能模块，用户可在 PC 端浏览商品时将商品加入购物车，管理购物车内商品并发起结算。

## 2. 功能需求

### 2.1 加入购物车
- 用户可在商品详情页点击【加入购物车】按钮将商品加入购物车。
- 加入购物车成功后，页面顶部【购物车图标】右上角显示当前购物车商品数量徽标。
- 若商品库存为 0，点击【加入购物车】提示"该商品库存不足"，不加入购物车。

### 2.2 购物车列表展示
- 购物车页面展示商品列表，包含：商品图片、商品名称、单价、数量、小计、勾选框、删除按钮。
- 每个商品的数量可编辑，通过【数量输入框】输入或【加减】按钮调整。
- 列表底部展示：已选商品数量、已选商品合计金额、【结算】按钮。

### 2.3 修改商品数量
- 数量输入框允许输入 1~999 的整数。
- 输入超过商品库存的数量时，提示"该商品库存不足"，数量自动回退到当前库存值。
- 输入 0 或负数时，提示"数量不能小于1"，数量回退到 1。
- 输入非数字字符时，提示"请输入有效数字"，清空非法输入。
- 修改数量后，商品小计金额和底部合计金额实时同步更新。

### 2.4 删除商品
- 点击单个商品的【删除】按钮，弹出确认删除弹窗。
- 点击确认后删除该商品，列表和底部汇总同步更新。
- 点击取消则关闭弹窗，不做任何修改。

### 2.5 全选/取消全选
- 列表顶部提供【全选】复选框。
- 点击【全选】时，所有商品勾选框均被选中；再次点击取消全选。
- 当所有商品均被选中时，【全选】复选框自动勾选。
- 取消任一商品选中时，【全选】复选框自动取消勾选。

### 2.6 结算
- 至少选中 1 个商品时，【结算】按钮可点击；无选中商品时【结算】按钮置灰不可点击。
- 点击【结算】后跳转到确认订单页面，已选商品信息带入订单。
- 若选中商品中存在库存不足的商品，提示"部分商品库存不足，请调整后重新结算"，不进入订单页。

### 2.7 购物车空状态
- 当购物车内无任何商品时，展示空状态页面，包含空购物车图标和文案"购物车空空如也，快去选购吧"及【去逛逛】按钮。
- 点击【去逛逛】跳转到商品列表页。

## 3. 非功能需求
- 页面响应时间不超过 2 秒。
- 数量修改后金额更新需实时（无刷新）。
- 购物车数据需在用户会话期间持久保存。
